ADJUSTMENT SUPPORT: how to run it on your computer
===================================================

1. Install Node.js (once). Go to https://nodejs.org, download the "LTS" version, run the installer, accept the defaults.

2. Unzip this folder somewhere you will keep it, for example Documents.

3. Start the app:
     Windows : double-click  start-windows.bat
     Mac     : double-click  start-mac.command
               (first time only: right-click it, choose Open, then Open again)
     Linux   : run  ./start.sh

   The first start takes a few minutes while it installs and builds. After that it takes seconds.
   Your browser opens at http://localhost:3000. If it does not, open that address yourself.

4. First visit: choose "First time here" and create your account (an email and a password of 10 or more characters).
   The account lives only on your computer.

5. To stop the app, close the window that opened when you started it.

UPDATING TO A NEWER VERSION
- Download the new zip. Open the folder where you already run Adjustment Support, close the app window, then extract the new zip into that same folder and choose "Replace" / "Replace all" for any files it asks about.
- Your sessions are not touched (they live in the hidden ".data" folder, which the zip does not contain). Then start the app as usual: it notices the new version and sets itself up again (a few minutes once).
- Before updating, it is wise to copy the ".data" folder somewhere safe.

YOUR DATA
- Everything you save is in the folder named ".data" inside this folder. Copy it somewhere safe now and then as a backup.
- To move to a new computer, copy the whole folder, including ".data".
- Forgot your password? Stop the app, open a terminal in this folder and run:  node scripts/set-password.mjs you@example.com "a new password of 10+ characters"

AI DOCUMENT SCANNING (optional)
- The app can read PDFs, photos and screenshots, Word, Excel, CSV and text files and pull out the subject's details, a table of sales, or market listings. You always review and correct what it found before anything is saved.
- It needs your own Anthropic API key (create one at console.anthropic.com; usage is billed by Anthropic to you).
  1. In this folder, copy the file named ".env.example" to ".env.local" (if you do not already have one).
  2. Open ".env.local" in Notepad and put your key after ANTHROPIC_API_KEY=
  3. Close the app window and start it again.
- The file you scan is sent to Anthropic to be read. The app does not keep a copy. Do not scan anything you are not allowed to send.
- Where to find it: "Scan a document (AI)" on each dataset card, "Fill from a document (AI)" in the subject form, and "Scan a document (AI)" on the Market analysis screen.

DASHBOARD
- "Dashboard" in the top bar shows three things: General (all your sessions), This session (progress, how much the methods agree, data quality, market snapshot) and Property data (prices, sizes, ages and timing of the sales, plus the sales most like the subject).

USING IT
- New session: pick the effective date, then drop in the two MLS exports (the sales around the subject, then the wider neighborhood).
- Enter the subject (address, GLA, lot size, baths, garage). Optional: quality, condition and your cost per square foot for depreciated cost.
- Each feature (GLA, lot size, baths...) shows every method's result; set the adjustment, mark it Done.
- Export: summary, comments and the full workfile zip (with an activity log).

SENDING SALES AND ADJUSTMENTS TO a la mode TOTAL
- In TOTAL: enter the subject, add at least one comparable column to the sales grid, then save the report as XML (UAD).
- In the app: open the session, choose Export, then "Fill a TOTAL report". Tick the sales to place as comps, pick your XML file, and a copy named "...-adjusted.xml" downloads. Your original file is not changed.
- In TOTAL: File > Open UAD XML on the copy. Review it, especially quality, condition, view and the "other" feature lines, which the app cannot know.
- Load your MLS file again in a session if its sales show "no address on file".
